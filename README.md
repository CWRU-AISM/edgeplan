# edgeplan

EdgeSense prototype plan, Nov 5 to Dec 1, 2026, as an editable schedule page.

**Site:** https://cwru-aism.github.io/edgeplan/

- **Edit on the site.** Drag a bar to move it, drag its ends to change dates, click a bar or task name to edit it. Use + Task and + Track to add items.
- **Save to GitHub** commits `index.html` to this repo under your own GitHub account. You need write access to this repo and a fine-grained token with *Contents: Read and write* on it. The page asks for the token once and keeps it only in your browser. The site updates about a minute after a save.
- **Export .xlsx** downloads the schedule, a colored timeline, and the decisions, handoffs and risks tables.

All plan data lives inside `index.html`, in the `plan-data` JSON block.
